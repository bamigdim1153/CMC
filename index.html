Actualización diaria a las 7:00 a. m.

Power Query solo puede ejecutarse dentro de Excel. El dashboard detecta automáticamente cada cambio del libro conectado; el programador de Windows se encarga de abrir, refrescar y guardar el archivo.

Descarga el automatizador

Guárdalo en la misma carpeta que UNION_Live_OPT.xlsx.

Crea una tarea diaria

En Programador de tareas de Windows, usa las 07:00 y selecciona “Ejecutar solo cuando el usuario haya iniciado sesión”.

Configura la acción

Programa: powershell.exe

-NoProfile -ExecutionPolicy Bypass -File "C:\RUTA\Actualizar_UNION_7AM.ps1"
Conecta el Excel una vez

Usa “Conectar Excel”. Mientras el dashboard esté abierto, revisará el archivo cada minuto y actualizará todos los visuales.
